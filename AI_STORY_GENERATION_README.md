# AI-Powered Story Generation for Reading Comprehension

## Overview

The reading comprehension component now features AI-powered story generation using OpenAI's API. Each time you enter the reading comprehension section, you can choose between two types of stories:

1. **General Stories** - AI-generated stories on diverse topics
2. **Cultural Stories** - AI-generated stories focused on Mauritian culture and traditions

## Features

### 🎯 Dynamic Story Generation

- Every story is uniquely generated by AI
- Stories are tailored to your selected difficulty level
- No repetitive content - fresh stories every time

### 🌍 Two Story Sections

#### General Stories

- **Animals & Nature** 🦁
- **Adventure** 🗺️
- **Science** 🔬
- **Friendship** 🤝
- **Space** 🚀
- **Mystery** 🔍

#### Mauritian Cultural Stories 🇲🇺

- **Culture & Traditions** 🎭
- **History** 🏛️
- **Nature & Wildlife** 🌺

### 📚 Complete Learning Package

Each generated story includes:

- **Story Content** - Engaging narrative tailored to your level
- **Comprehension Questions** - 3 questions testing different skills:
  - Main idea or theme
  - Specific details or facts
  - Inference or critical thinking
- **Cloze Test** - Fill-in-the-blanks exercise
- **Detailed Explanations** - Learn why answers are correct

## Setup Instructions

### 1. Get OpenAI API Key

1. Visit [OpenAI Platform](https://platform.openai.com/api-keys)
2. Create an account or sign in
3. Generate a new API key
4. Copy the API key (starts with `sk-`)

### 2. Configure Environment Variables

Create a `.env` file in your project root with:

```env
VITE_OPENAI_API_KEY=your_openai_api_key_here
```

### 3. Fallback Mode

If no API key is provided, the system will use predefined fallback stories to ensure the feature always works.

## Technical Implementation

### Files Created/Modified

1. **`src/services/storyGenerationService.ts`** - Core service for AI story generation
2. **`src/hooks/useStoryGeneration.ts`** - React hook for story generation
3. **`src/components/ReadingModule.tsx`** - Updated component with new UI

### API Integration

The service uses OpenAI's `gpt-4o-mini` model with:

- Temperature: 0.8 (for creative variety)
- Max tokens: 3000
- JSON response format for structured output
- Proper error handling and fallback mechanisms

### Story Structure

Each generated story follows this structure:

```typescript
interface Story {
  title: string;
  content: string;
  questions: Array<{
    question: string;
    options: string[];
    correctAnswer: number;
    explanation: string;
  }>;
  clozeTest: {
    text: string;
    blanks: Array<{ word: string; position: number }>;
    answers: string[];
  };
  difficulty: number;
  topic: string;
  isCultural?: boolean;
}
```

## Usage

1. Navigate to the Reading Comprehension section
2. Choose between "General Stories" or "Mauritian Cultural Stories"
3. Select a topic that interests you
4. Wait for AI to generate your unique story
5. Read the story and answer comprehension questions
6. Review your results with detailed explanations
7. Generate a new story anytime!

## Troubleshooting

### API Key Issues

- Ensure your API key is valid and has sufficient credits
- Check that the environment variable is properly set
- The system will automatically fall back to predefined stories if the API fails

### Story Generation Errors

- Check your internet connection
- Verify OpenAI API status
- Try refreshing the page and generating a new story
